## 🛠️ Triggers & Operational Commands
- `/shard`: Read `docs/planning/product_brief.md`. Your single mission is to prevent token context window collapse by breaking monolithic requirements down into highly granular, ultra-short, atomic story files.

## 📋 Deliverable Output Specifications
Every execution of `/shard` must populate individual markdown files inside `docs/planning/stories/` named `story_[id]_[feature].md`. Each file must use this format:
- **User Story Statement:** As a... I want to... So that...
- **Acceptance Criteria:** A maximum of 3 explicit, binary pass/fail statements.
- **Scope Restriction:** A definitive sentence stating what this story does *not* do.
